04 Authentication & Authorization Flow

Login → Org Switch → Protected Route
① Register / Login
POST /auth/login → access_token (15 min) + refresh_token (30 days)
Passwords: argon2id (time=3, mem=64MB)
Token stored: accessToken → sessionStorage, refreshToken → memory only
↓
② Create / Switch Organization
POST /orgs/{id}/switch → new access_token with org_id in payload
JWT payload: { user_id, email, org_id, role, exp }
Every request must carry an org-scoped token
↓
③ Tenant Isolation on Every Query
Every DB query includes WHERE org_id = :org_id
org_id extracted from JWT — never from request body
Prevents cross-tenant data leaks at the service layer
↓
④ Token Refresh + Reuse Detection
401 → clearAuth() → redirect /login (no refresh attempt)
Refresh tokens: SHA-256 hashed in DB, one-time-use
Reused revoked token → revoke ALL tokens for that user
JWT Payload Structure
// Access Token (15 min)
{
  "sub": "uuid-of-user",
  "email": "user@example.com",
  "org_id": "uuid-of-org",  // after switch
  "role": "ORG_ADMIN",
  "exp": 1715123456
}

// RBAC Roles
SUPERADMIN > ORG_ADMIN > ADVISOR
ANALYST > CLIENT > VIEWER
Rate Limits (per IP)
POST /auth/register10/min
POST /auth/login10/min
POST /auth/refresh20/min

POST /ai/conversations30/min

07 AI Tool Calling — How the AI Reads Your Data

Streaming Chat Flow
① User message → POST /ai/conversations/{id}/messages
Validates: max 8000 chars, org context, conversation ownership
↓
② System prompt injected with org_id
7 injection-defense rules. Message history sent to Ollama.
↓
③ Tool calls (if LLM decides to call them)
Each call verified: portfolio_id must belong to org_id
↓
④ SSE stream back to browser (Server-Sent Events)
Each token streamed. Tool results inserted inline.
Available AI Tools
get_portfolio(portfolio_id)
Returns portfolio metadata + summary. Verifies org ownership before executing.
get_holdings(portfolio_id)
Returns current holdings with prices, values, unrealized P&L.
list_transactions(portfolio_id, limit?)
Returns recent transactions for a portfolio. Sorted by trade_date desc.
search_documents(query, types?)
Full-text search (FTS5) across portfolios, assets, transactions. Org-scoped.

08 Security Defence-in-Depth — 7 Layers

🔒 Infrastructure Ports bound to 127.0.0.1 only · Non-root Docker user (uid 1001) · read-only web container · no-new-privileges · SECRET_KEY ≥ 32 chars enforced at startup
🛡️ HTTP Headers CSP (default-src 'self') · X-Frame-Options: DENY · X-Content-Type-Options: nosniff · Referrer-Policy · Permissions-Policy (camera/mic/geo off)
⏱️ Rate Limiting slowapi per-IP · Login/register 10/min · Change-password 5/min · AI messages 60/min · Body size limit 1 MB JSON / 10 MB uploads
🔑 Authentication argon2id passwords · JWT access (15 min) + refresh (30 days, SHA-256 hashed) · Refresh token rotation + reuse detection (revoke all on reuse)
🏢 Tenant Isolation org_id on every DB query · Extracted from JWT only (never request body) · RBAC roles (SUPERADMIN → VIEWER) · Membership check on all org ops
📁 Input Validation Pydantic v2 on all inputs · File uploads: extension + MIME + filename chars + size · FTS5: named params (no SQL injection) · target param whitelist
🤖 AI Security Org-scoped system prompt with injection rules · Tool call ownership check (portfolio.org_id == request.org_id) · Message length limit (8000 chars) · SafeMessage HTML sanitization in browser
